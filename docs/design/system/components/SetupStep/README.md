First-run setup and the checks behind "Ready": grouped by what they protect, in order.

- Two groups: **It can wake you** (notifications, full-screen alarm, exact alarms, buzz on Mute) and **It can follow the bus** (precise location, battery). Optional ones last, marked optional.
- `is-done` shows a tick, `is-todo` the step number and one **Allow** button, `is-optional` a dash.
- One sentence each, about the rider's outcome ("So the alarm shows over the lock screen").
