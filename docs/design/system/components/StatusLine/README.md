The alarm's state in words and colour, at the top of every riding surface and on Now when idle.

- **Armed** (`ns-armed`): the alarm is set from live GPS. "Armed · rings about 45 s before Harbour St".
- **Backup alarm** (`ns-backup`): GPS lost or still waiting for the bus; the failsafe is set. Say when: "Backup alarm · 07:49".
- **Ringing** (`ns-ring`): shown for the second before the alarm screen covers everything.
- **Not ready** (`ns-ring`): a required setup check is off. Tapping opens Setup.
- **Ready** (`ns-idle`): no trip, all checks green.
- Never colour alone: the word always leads. One status line per screen.
