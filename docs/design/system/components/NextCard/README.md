After "I'm awake": what to do now, before anything else.

- Eyebrow says the moment ("Now"), the main line is the action ("Get off at Harbour St"), the second line what happens next ("Then: Bus 3 to Hill Ave. It will ring again.").
- For an early safety ring the action is "Stay on: Harbour St is 4 km away" and the next line says it will ring again near the stop.
- While you slept goes **below** this card, never above it. Done closes both.
