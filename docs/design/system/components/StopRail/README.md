A route's buses in order, as a vertical line of stops: in the route editor, and on Now during a transfer.

- `is-done` for buses you're off, `is-now` for the current one, plain for what's ahead.
- Each row: the stop you get off at (bold), a second line (the alarm, or "no alarm: you stay awake for this one"), and an optional trailing value (distance, or Edit).
- Don't use it for anything but a route's buses.
