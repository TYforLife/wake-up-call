Now, idle: the route you most likely want, ready in one tap, with the others below.

- The suggested route (by time of day, then where you are, then the one you last used) gets the big card and **Start <route name>**.
- Underneath: the buses as a one-line summary ("Central Station → Harbour St"), and how sure it is ("Learned from 12 rides").
- Other routes are compact rows with their own Start.
- A route with a missing stop can't start: its button is disabled and the row says which stop.
