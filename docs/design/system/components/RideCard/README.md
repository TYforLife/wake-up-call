The live trip on Now: where you get off, how far, how long, and that the alarm is set. The whole screen while riding.

- The consumer provides: stop name, bus number in the route ("Bus 2 of 2"), distance, minutes, progress (0–1), status (Armed / Backup alarm), the alarm time.
- Order is fixed: status line, "Get off at", stop name (`stop-name`), the two numbers (`number-xl`), progress, then the alarm line in `body-small`.
- Waiting for the bus: minutes read "—" with "once the bus moves"; status is Backup alarm.
- GPS lost: status turns `backup` with how long ago; numbers keep the last values, greyed to `ink-muted`.
- The card itself is tappable (opens details); its only button lives below it: I'm off this bus.
