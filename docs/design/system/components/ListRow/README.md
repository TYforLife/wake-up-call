The building block of every non-map screen: a title, a second line, and what it does at the end.

- The consumer provides the title (`row`), an optional second line (`secondary`) and one trailing element: a chevron (opens), a pill (acts), a switch (toggles) or a tick (done).
- Rows divide with a `line` hairline; the last row has none. No card behind them.
- A problem goes on the second line in `danger` ("Hill Ave needs a stop").
